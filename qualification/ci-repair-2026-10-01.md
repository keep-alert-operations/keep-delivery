copied from a developer's general-purpose GitHub login. The dedicated secret
must be supplied through the approved credential process, then the failed jobs
rerun. See [the exact consumer repositories and access scope](../docs/repository-workspace.md#build-and-ci).

## Revisions and local execution

The committed `workspace/manifest.json` identifies the exact revisions tested for
the ten sibling repositories. Delivery verification used
`84d882f771bc2286e626e4bbd35e1cd52002609c` before the documentation and manifest
changes recorded here; document validation was repeated afterward. The design
checker fix was tested at the new pinned commit. No service/package source or
dependency lock changed during this audit.

Environment: Windows, Python 3.13.5, uv 0.10.8, Node.js 22.17.1 and npm 10.9.2.
Each of the seven Python repositories needing private dependencies used a separate
ignored environment selected with `UV_PROJECT_ENVIRONMENT`, preserving the normal
editable development environments. Commands, run from each owning repository:

```text
uv sync --locked --all-extras
uv run --locked --all-extras ruff check src tests
uv run --locked --all-extras pytest tests/unit -q -p no:cacheprovider
uv build --wheel
```

Pytest ran only where an owned unit suite exists. Total: 545 passed, 65 skipped.
Delivery's skips require database/service bindings absent from the current CI job;
they are not integration qualification. Heavy native-CEL suites ran serially.
Delivery's locked environment also passed `qualification/check_contracts.py`,
`qualification/verify_boundaries.py` and `qualification/verify_documents.py`.

Frontend verification used a disposable checkout of its pinned commit, with a
local Git credential helper and the workflow's SSH-to-HTTPS rewrite for the private
contracts dependency. `npm ci`, `npm run generate`, generated-file diff,
`npm run format:check`, `npm run typecheck` and `npm run build` passed. The first
Windows formatting check failed on checkout CRLF endings; the committed Git blobs
contain LF. Repeating in a fixture with LF endings matching Linux CI passed
without source changes. Local authentication does not establish Actions access.

The eight private-dependency hosted workflows remain blocked on credential setup;
later hosted steps cannot yet be declared passing. Image builds, company-service
integration and production rollout were not performed. Existing DEL-01 through
DEL-08 qualification gates remain unchanged.
